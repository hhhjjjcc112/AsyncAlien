## 1. 引言（预计完成：2026-05-12）
1. 研究背景与意义
  - 传统内核逐渐积累复杂性，导致代码路径耦合加深、漏洞和故障影响面扩大，修改成本持续上升。
  - Alien 将内核功能拆分为多个故障隔离域，降低模块故障对整体系统的影响。
  - 现有 Alien 设计已验证了域隔离、共享堆通信、域加载等机制的可行性，但其最初实现主要面向 RISC-V 平台。
  - x86-64 平台具有不同的启动/中断/ABI 语义，迁移过程需要重构平台抽象。
  - vDSO、协作调度、驱动域复用等机制位于用户/内核边界的关键路径，既影响系统调用与时间获取等高频操作的性能，也决定了域隔离方案能否在实际场景中保持可用性。
  - 因此，研究 Alien 在 x86-64 平台上的移植与演进，不仅有助于验证其架构抽象的可迁移性，也能为多架构隔离内核的设计提供实现经验与工程依据。
2. 研究目标与问题陈述
  - 目标：在不破坏现有 RISC-V 路径的前提下，建立 x86-64 可运行链路，使系统能够完成启动、设备发现、域加载、多核启动、进入用户态；为 vDSO、协作调度预留接口。
  - 问题：如何抽象启动流程、内存布局、中断控制器、设备发现和系统调用入口，使 x86-64 与 RISC-V 共用尽可能多的代码，同时维持各自语义正确；如何把 vDSO 与 syscall 纳入统一设计以减少高频路径分叉。
3. 主要贡献点
  - 完成 Alien 从 RISC-V 到 x86-64 的系统性迁移方案与实现要点。
  - 提出并实现平台抽象，降低架构分叉的维护成本。
  - 设计并集成 vDSO，实现快路径/回退协同并验证其性能收益。

## 3. 系统架构与设计（重写）
本章按三大主题展开：Alien 原始设计对齐；x86_64 移植的设计与落地要点；引入 vDSO 的设计、映射与与域隔离/调度的协同。

3.1 Alien 原始设计（基于语言机制）
- 设计目标与分层：TCB 与域分离，unsafe 汇聚到小范围。
- 域模型与生命周期：ELF 镜像打包→地址空间准备→重定位→call_main/替换。
- 域间通信：SharedHeap、代理 RPC、所有权与回收。

3.2 将 Alien 移植到 x86_64
- 启动与早期初始化：boot→long mode、早期 frame 分配、vDSO 预留。
- 中断/Trap 与 Syscall 适配：GDT/TSS/IDT、LSTAR/int0x80、trampoline。
- 虚拟内存与 ABI 兼容：VSpace 抽象、auxv 注入（AT_SYSINFO_EHDR）。
- 设备发现与驱动接入：平台枚举→统一设备描述→驱动域加载。

3.3 引入 vDSO
- 设计定位：快路径（vDSO）与慢路径（syscall）协同，保证可回退与隔离语义。
- vVAR / vDSO 映射：布局、seq 无锁一致性方案。
- 用户端解析与回退策略：auxv 注入、用户库优先解析 vDSO、失败回退 syscall。

## 5. vDSO 实现（纯实施细节）

本章仅关注 vDSO 在 AsyncAlien 中的工程实现与验证：构建产物、vVAR 布局与内核刷新、用户态集成（auxv/解析/回退）、构建/集成脚本及性能验证方法。

5.1 vDSO 构建模板与产物
  5.1.1 `vdso_crate_template` 引入与定制
    - 要点：说明仓库如何基于 `vdso_crate_template` 生成 vDSO crate（目录：`vdso/`）并定制导出符号、构建脚本与 ABI 兼容处理。
    - 代码对照：`vdso/vdso_impl/`、`vdso/Cargo.toml`、`build/vdso`（若存在构建包装脚本）。

  5.1.2 构建产物与交付形式
    - 要点：产物类型（静态 .o/.a、ELF .so 或直接嵌入内核的二进制段）、如何在镜像/运行时将其映射到进程地址空间。
    - 代码对照：`vdso/target/` 产物、`kernel/src/vdso.rs` 中的映射调用点。

5.2 vVAR 布局与无锁一致性策略
  5.2.1 内存布局与权限分隔
    - 要点：推荐布局 `[vVAR (RW)][vDSO (RX)]`，vVAR 包含 `seq`、`realtime_ns`、`monotonic_ns` 等字段，确保用户态只能读取 vVAR 而不能写。
    - 代码对照：`vdso/vdso_impl/src/lib.rs`、`kernel/src/vdso.rs`。

  5.2.2 无锁更新与读路径
    - 要点：内核通过 seq 奇偶位或版本号写入 vVAR，用户态先读 seq，再读数据，再读 seq；两次 seq 不同时回退到 syscall 或重试。
    - 代码对照：`vdso/vdso_impl/src/lib.rs` 中的读序列实现。

5.3 vDSO API 导出与用户态解析
  5.3.1 导出函数与符号约定
    - 要点：导出 `__vdso_clock_gettime` 等函数，保证符号/ABI 与用户库一致。
    - 代码对照：`vdso/vdso_impl/src/api.rs`。

  5.3.2 运行时映射与 auxv 注入
    - 要点：在进程创建阶段映射 vDSO/vVAR 并注入 `AT_SYSINFO_EHDR`，用户库优先解析使用 vDSO，必要时回退 syscall。
    - 代码对照：`kernel/src/vdso.rs`、`user/userlib/src/vdso.rs`。
