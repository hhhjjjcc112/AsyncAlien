# 北京理工大学本科生毕业设计（论文）格式规范提要

本文档基于《北京理工大学本科生毕业设计（论文）指导手册（2024年11月）》和《北京理工大学本科生毕业设计（论文）模板（2023年12月）》提取的关键格式要求。

---

## 一、正文格式要求

### 基本格式
- **字体**：宋体
- **字号**：小四（12pt）
- **行距**：固定值 22 磅
- **段落间距**：段前、段后均为 0 行
- **首行缩进**：2 个汉字（使用模板中的"正文"样式自动实现）

### 应用范围
这套格式适用于：
- 摘要正文
- 正文各章节
- 结论部分
- 致谢部分

---

## 二、标题层级与格式

### 一级标题（章标题）
- 格式：第 N 章  标题名称
- 示例：`第1章 一级题目`
- 特点：加章号，独占一行

### 二级标题（节标题）
- 格式：N.M  二级标题名称
- 示例：`1.1 二级题目`
- 特点：编号 + 标题

### 三级标题（小节标题）
- 格式：N.M.K  三级标题名称
- 示例：`1.1.1 三级题目`
- 特点：编号 + 标题

### 特殊标题
- **摘要**：单独排写（居中或左对齐），标题为"摘　　要"
- **目录**：单独排写，标题为"目　　录"
- **结论**：单独排写（不加章号），标题为"结　　论"
- **参考文献**：单独排写（不加章号），标题为"参考文献"
- **附录**：单独排写（可加序号 A、B、C...），标题为"附　　录"
- **致谢**：单独排写（不加章号），标题为"致　　谢"

---

## 三、图表要求

### 图的格式
- **位置**：居中排放
- **图注位置**：标在图下方
- **字体、字号**：宋体、五号
- **对齐**：居中
- **行距**：1.25 倍
- **间距**：段前、段后均为 0 行
- **与正文间距**：图表与上下文之间各空一行
- **编号格式**：图 1-1、图 1-2、图 2-1 等（按章编号）

### 表的格式
- **位置**：居中排放
- **表头位置**：标在表上方
- **字体、字号**：宋体、五号
- **对齐**：居中
- **行距**：1.25 倍
- **间距**：段前、段后均为 0 行
- **与正文间距**：表与上下文之间各空一行
- **编号格式**：表 1-1、表 1-2、表 2-1 等（按章编号）

---

## 四、公式要求

- **位置**：公式中心排放
- **标注位置**：标注应于该公式所在行的最右侧
- **长公式换行**：只可在符号处（+、-、*、/、≤、≥ 等）转行
- **文中引用**：在标号前加"式"，如"式（1-2）"
- **编号格式**：（章号-序号），如（1-1）、（1-2）、（2-1）等

---

## 五、摘要要求

### 中文摘要
- **字数**：300-500 字
- **格式**：按正文格式（宋体、小四、行距 22 磅、首行缩进 2 个汉字）
- **内容**：
  - 应具有独立性和完整性
  - 应概括而扼要地反映出本论文的主要内容
  - 包括研究目的、研究方法、研究结果和结论等
  - 特别要突出研究结果和结论
- **禁用内容**：不可出现参考文献、图、表、化学结构式、非公知公用的符号和术语

### 英文摘要（Abstract）
- **内容**：与中文摘要的内容应一致
- **格式**：按正文格式

### 关键词
- **数量**：通常 3-8 个
- **格式**：关键词间用分号（；）分隔
- **位置**：位于摘要之后
- **示例**：关键词：北京理工大学；本科生；毕业设计（论文）

---

## 六、参考文献格式

### 总体要求
- 按国家标准《信息与文献参考文献著录规则》（GB/T 7714—2015）编写
- 按文献在正文中出现的先后顺序编号
- 编号用方括号标注，如 [1]、[2] 等

### 常见文献类型
| 文献类型 | 代码 |
|---------|------|
| 普通图书 | M |
| 期刊 | J |
| 会议录 | C |
| 学位论文 | D |
| 报告 | R |
| 专利 | P |
| 标准 | S |
| 报纸 | N |

### 参考文献书写示例

**期刊**：  
`[序号] 主要责任者. 文献题名[J]. 刊名, 出版年份, 卷号(期号): 起止页码.`

**图书**：  
`[序号] 主要责任者. 文献题名[M]. 出版地: 出版者, 出版年: 起止页码.`

**学位论文**：  
`[序号] 主要责任者. 文献题名[D]. 保存地: 保存单位, 年份.`

---

## 七、页面布局

### 页面设置
- **纸张**：A4
- **页边距**：一般为上下左右各 2-2.5cm（按学校要求具体设置）
- **页码**：从摘要页开始编号（用罗马数字 I、II、III...；正文开始改用阿拉伯数字 1、2、3...）

### 页码位置
- **摘要及前置部分**：页码位置通常在页脚中心或右下
- **正文及后置部分**：同样位置

---

## 八、原创性声明与授权声明

### 要求
- 必须单独成页
- 包含两部分：
  1. **原创性声明**：表明论文是独立完成的成果
  2. **使用授权声明**：确认学校的保管、使用和传播权

### 签署
- 本人签名、日期
- 对于授权声明，还需指导老师签名、日期

---

## 九、目录要求

### 内容
- 列出所有章节标题及其对应页码
- 从摘要开始，到附录、致谢为止

### 格式
- 按照章、节、小节的层级关系缩进显示
- 使用 Word 的"目录"功能自动生成更为规范

---

## 十、论文结构顺序

1. 封面
2. 原创性声明与授权声明
3. 摘要（中文）
4. Abstract（英文）
5. 目录
6. 正文（第 1 章至第 N 章）
7. 结论
8. 参考文献
9. 附录（如有）
10. 致谢

---

## 十一、写作建议

### 引言部分特点
- **字数**：通常 2-3 页（约 2000-3000 字）
- **内容结构**：
  1. 研究背景与意义
  2. 相关研究或现状
  3. 研究目标与问题陈述
  4. 本论文的贡献或创新点
  5. 论文结构说明
- **语言**：学术严谨，避免口语化

### 论文整体建议
- 各章字数应大致相当（除引言、结论可略短外）
- 避免出现孤立的一二级标题（每个标题下应至少有内容或下级标题）
- 图表要有序编号和清晰说明
- 参考文献应准确完整
